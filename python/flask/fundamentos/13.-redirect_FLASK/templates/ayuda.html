Guía de Conceptos Básicos

¿Qué es una solicitud POST?

Una solicitud POST se utiliza para enviar datos al servidor. Es el método que usamos en formularios para crear, actualizar o eliminar información.

Ejemplo en Flask: @app.route("/registrar", methods=["POST"])

Características: - Los datos viajan en el cuerpo de la solicitud - No son visibles en la URL - Se accede a los datos mediante request.form

¿Qué es una solicitud GET?

Una solicitud GET se utiliza para solicitar información al servidor. Es el método que usamos para obtener una página o recurso.

Ejemplo en Flask: @app.route("/mostrar")

Características: - Los datos viajan en la URL (query string) - Son visibles en la barra de direcciones - Se accede a los datos mediante request.args

¿Para qué sirve redirect()?

redirect() es una función de Flask que indica al navegador que debe navegar a otra URL.

Ejemplo: return redirect("/mostrar")

Beneficios: - Evita el reenvío de formularios al recargar la página - Separa el procesamiento de la visualización - Implementa el patrón PRG (Post-Redirect-Get)

¿Por qué request.form está vacío después de redirect?

request.form solo contiene datos durante la solicitud POST original.

Cuando realizamos redirect(), el navegador inicia una nueva solicitud GET. Esta nueva solicitud no tiene formulario, por lo que request.form está vacío.

Los datos del formulario no se transfieren automáticamente en la redirección.

Patrón PRG (Post-Redirect-Get)

Formulario → POST /registrar → Procesar datos → redirect() → GET /mostrar → Mostrar resultado
